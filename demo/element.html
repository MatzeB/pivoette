Web component

One script tag defines <pivoette-table> and <pivoette-editor>. No React on the page, no build step. Rearrange the table with the panel, or with the + buttons and drag handles on the table itself. Reset puts it back.

The markup

<script src="https://matzeb.github.io/pivoette/pivoette-element.js" defer></script>

<pivoette-editor for="downloads"></pivoette-editor>
<pivoette-table id="downloads" editable>
  <script type="application/json">{ "data": …, "meta": …, "view": … }</script>
</pivoette-table>

What the page sees
